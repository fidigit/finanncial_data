# v0.0.6 备注及奖金状态回传

部署命令及数据库位置不变，没有新增运行依赖。升级前备份data/app.db及参考数据.csv。

## 使用

1. 首页销售/市场奖金表，备注列的确认/修改仅编辑备注；带入当前显示内容，可以清空。金额、提点、奖金和状态不受备注保存影响。
2. 导出XLSX会得到例如销售奖金表_20261112-183500_v1.xlsx。同秒多次导出由系统依次分配v2、v3；其他秒从v1开始。
3. 保留文件名后缀、BD子表名称和所有行。A–P/S为无填充背景、深灰字体并锁定只读，只有Q是否发放、R是否退款可改为是/否/待确认，不得留空或填公式。
4. 在对应表的导入XLSX按钮，或数据导入页选择文件，查看版本、记录数及状态变更预览，再确认导入。
5. 每个账号只接受最后一次销售或市场导出的文件。新的销售/市场导出会替换该账号先前最新版本；请先回传一张表，再导出下一张表。其他账号导出不会作废你的文件，会议导出也不影响此版本。
6. 导入成功后此版本不可重复使用；再次修改请重新导出。若备注、源数据、计算结果或权限在导出后改变，也需重新导出。

## 数据边界

- 每位BD只可编辑本人备注及回传本人账单状态，管理员按授权范围操作。
- 只回写发放与退款状态，不修改奖金或退款扣奖算法；备注通过网页维护。
- Excel保护用于限制编辑，服务器仍会独立验证所有只读单元格和版本，不依赖Excel保护本身。
- 服务器记录最新后缀、随机内部文件标识、来源行及确认版本快照，整批验证和更新在同一事务中提交。
- XLSX上传限制10MB及解压大小，拒绝公式、宏、外部链接和异常XML；上传文件不执行，也不存入业务文件目录。
