# v0.0.5 配置维护

启动命令与原版本一致。首次启动保留现有奖金汇总数据和2025年方案，迁移到按年份存储，旧数据留存于数据库。

- 首页销售奖金表“重置”右侧，打开奖金汇总表、奖金方案、公共常数。
- 奖金汇总表默认显示最新已有季度。选择空季度，点击中心加号，沿袭严格上一季度目标；2026Q4之后可沿袭到2027Q1。新增BD没有上一季金额时保留空白，请填写后保存。
- 奖金方案默认显示最新已有年份；原有服务数据为2025年。2026年、2027年按顺序点击沿袭；订单按付款年份查本年度规则，不自动借用其他年份。未建年度方案的非VIP订单保留待设置规则。
- 全部奖金来源在同一页，不分页。可将是否计入提成范围设为是/否；点击新增奖金来源填写名称，例如马克智能水电表，然后保存本年方案。
- 团队VIP继续使用既有金额下限公式，不由服务列表覆盖。
- 公共常数与齿轮共用全局参数；修改后点击保存，立即用于全部BD和季度的计算与导出。
- 保存成功才生效；切换年份、季度或关闭弹窗时，未保存草稿会提示放弃。多人同时维护若发生版本冲突，请重新加载。
- 管理员可维护；BD只能查看本人目标以及公共规则。

部署迁移时继续保留data/app.db与参考数据.csv。生效配置保存在数据库内，不需要在每次启动时重复导入Excel。
