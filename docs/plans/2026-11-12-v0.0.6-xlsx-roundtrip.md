# v0.0.6 备注与受控XLSX回传计划

范围：仅销售/市场19列表，会议表保持原样（用户已确认）。

1. 备注弹窗仅保留文本域，带入网页当前显示备注，可修改或清空；专用接口只合并备注，不改比例、提点、奖金和状态。
2. XLSX以姓名分Sheet，A–P和S灰底锁定，Q/R解锁且下拉仅允许是/否/待确认；表头锁定，继续冻结首行。
3. 服务器分配yyyymmdd-hhmiss_vn后缀，系统同秒导出递增n、下一秒重新v1。后台记录每位用户最新销售/市场导出版本、随机文件标识、行身份与导出快照；保留文件内自定义属性，不新增可见业务列。
4. 导入入口支持预览、确认两步，只接受本人最后一次导出文件；同时核对文件名、文件内标识、类型、权限、所有只读单元格、行身份、现有记录版本和计算快照。只允许Q/R严格三元值；整批验证后原子回写，阻止旧版本、篡改、重复回传和其他用户文件。
5. XLSX解析限制文件大小、解压体积、工作表/单元格数量，拒绝公式和异常XML；不执行上传文件。沿用原生OOXML导出，增加保护样式和校验，无需新依赖。
6. 导出文件名采用服务端响应，上传预览说明更新行数。BD只能回传本人，备注也仅能编辑其授权可见记录；其他参数与公式权限保留。
7. 验证列锁/灰底/下拉、同秒递增与跨秒复位、双重版本校验、备注预填和清空、事务防部分导入、权限、导出/网页回读一致，再备份并启动v0.0.6。
