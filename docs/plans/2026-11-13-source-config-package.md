# 源头配置包实施计划

目标：提供无需替换数据库、无需新建项目目录的一次性配置导入包。

设计：只传输五类历史源头样例及允许名单中的季度目标、年度方案、公共参数。不包含账号、查询凭证、账单或其他设置。默认按BD季度、服务名和参数名补缺，保留服务器现有值。显式覆盖模式只替换包内同名配置。预检不写入；正式导入前一致性备份数据库和样例，事务写入设置并提高版本号。包内脚本仅依赖Python标准库。

1. 添加scripts/source_config_bundle.py，提供export和import子命令、校验、差异报告及自动备份。
2. 添加隔离数据库测试：账号/数据源/备注不变；默认合并、显式覆盖、校验失败、重复导入。
3. 从本机只读生成私有ZIP，包含脚本及配置JSON，不提交业务数据。
4. 用当前数据库副本与缺少配置的副本验证，提供现有服务器停止服务、预检、导入、重启命令。

边界：历史拆分订单、订单和Z仍为预览，不自动匹配实际账单。不迁移整个app.db。不更新应用版本。
