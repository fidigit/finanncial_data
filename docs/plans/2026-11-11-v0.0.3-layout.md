# v0.0.3 全列展示

用户确认采用：释放页面宽度、按字段分配宽度、表头和内容自动换行、紧凑表格样式、整表等比缩放。拒绝摘要或隐藏字段。

三张奖金表默认直接展示全部字段，销售/市场各19列，会议14字段及管理员操作列。按字段宽度分配约1500px的奖金表基础布局；可用宽度足够则铺满并保持100%，不足则按可用宽度/基础宽度等比缩放。ResizeObserver同步窗口、导航及全屏变化。长文字完整换行，不使用省略号或展开详情。分页按钮在缩放区域之外。

首页默认64px图标导航，允许展开；内容取消1700px最大宽度限制，减少两侧空白。表格可进入页面全屏，保留编辑表单正常显示，Esc或按钮退出，退出恢复页面滚动。

验证：TypeScript检查、Vite构建通过；Edge浏览器1920、1440、1280宽度检查列数量、表格边界和单元格溢出均通过；全屏、编辑表单、Esc和导航切换通过。源码未改变奖金计算、权限或导出逻辑。

小屏幕下缩放会使字号变小，这是全部列同时显示的物理限制；当前版本优先满足用户提出的全列无横向滚动目标。可点击全屏扩大空间。
