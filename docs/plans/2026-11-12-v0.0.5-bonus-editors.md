# v0.0.5 奖金配置实施计划

目标：在现有80%源头弹窗内维护季度目标、年度奖金方案及全局公共常数。

1. 保留现有目标为初始季度；按BD/季度编辑。空季度提供中心加号，一键复制严格上一季度目标，跨年正确；补齐全部BD，上一季无值的BD待填写，不擅自生成金额。
2. 将原2025年方案迁移到按年存储；方案全页展示不分页，可修改是否计提及新增服务；新年仅在点击沿袭上一年后建档。订单按付款年份读取方案，VIP沿用独立金额公式。
3. 新建管理员配置API，校验姓名、唯一服务名、金额及提点，使用版本防覆盖，审计保存/沿袭。保留旧规则源作为迁移备份；禁止旧全局服务入口覆盖按年数据。
4. 公共常数复用齿轮同一global设置与版本；保存触发表格刷新和打开的齿轮重新读取。
5. 管理员可编辑，BD仅查看本人目标及公共方案；季度、年份切换或关闭时提示未保存草稿。
6. 测试跨年复制、重复沿袭冲突、年份隔离、目标与奖金计算联动、导出一致、权限及常数双向同步；备份、构建、隔离浏览器验收、重启。

版本更新到v0.0.5，不推送GitHub。
