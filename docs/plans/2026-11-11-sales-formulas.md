# 销售公式配置实施计划

目标：仅增强销售19列，版本保持0.0.3；齿轮查看公式和变量，右上角配置赋值，计算与导出一致。

架构：独立sales参数命名空间，按BD+季度配置目标/门槛/提点，按原记录键配置订单变量，按服务保存销售专属规则。Decimal计算，先全量同人同季度时间排序累计，再筛选分页。保留原人工确认优先及审计，不修改市场/会议或CSV。

1. 新增独立销售计算器与公式/变量元数据，支持分摊、资格、累计、起提、跨档和退款判断。
2. 增加版本校验的变量读写接口，仅管理员写；BD只能读取本人数据。销售导出复用相同投影。
3. 销售表头添加齿轮弹窗；右上角变量面板按季度、订单、服务分组。辅助核对变量标注不直接参与奖金，计算中间量只读。
4. 测试目标边界、门槛、续费、排除项累计、分摊/精度、缺失值、过滤不改变计算、权限与并发；构建及浏览器验证19列和市场隔离。

口径：遵循Excel默认累计包括不计提基数、按季度、总基数3万元起提；自动跨档替代人工Z开关并统一校验门槛。基数四舍五入2位，自动奖金保留Decimal精度（界面2位，未执行发放结算取整）；未知服务/缺失输入待配置，退款仅识别不自动冲减，未接入发放流水。
