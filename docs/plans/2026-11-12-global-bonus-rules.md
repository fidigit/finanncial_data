# 公共奖金规则实施计划

目标：启用2025年奖金方案为实际服务规则源；所有BD和季度共用公式与公共参数，直接营收目标仍按BD、季度读取。

1. 新增公共规则源模块：启动时从本地已提取的完整方案导入、验证并持久化；保留源头说明，重启不覆盖生效配置，未知服务保留待配置。
2. 销售及市场计提资格复用同一查询；团队VIP应用全局金额下限，人工单笔确认仍优先；销售计算及导出共用同一结果，会议不套用订单公式。
3. 公共参数独立版本保存与全局试算；旧BD季度设置只读取target，其他旧值停用且保留原数据。目标按BD、季度严格匹配，不把Q3目标套入Q4。
4. 蓝紫齿轮显示全局作用范围，样例姓名单列说明；更新实际生效源头展示，参数保存后同步刷新销售及市场表。
5. 测试跨BD跨季度、目标独立、预览无写入、版本冲突、服务是否/未知/VIP/人工覆盖、权限和导出；构建、浏览器验证后备份并重启。

版本保持v0.0.4，不推送远程。
